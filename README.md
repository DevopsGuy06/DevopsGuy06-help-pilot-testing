# DevopsGuy06-help-pilot-testing

This is a zero-cost local pilot using SYNTHETIC/DEMO data only.

## Run
1. Install Python 3.10+
2. `pip install flask`
3. `python app.py`
4. Open `http://127.0.0.1:5000`
5. Test: `PILOT1001` / `PILOT1002`

## Important
Do not upload the full real depositor database or unrestricted PII to a public free host.
